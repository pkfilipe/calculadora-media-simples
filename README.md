# Calculadora de Média Simples

Projeto simples em HTML, CSS e JavaScript que recebe 3 notas e calcula a média.

🔗 **Link Online (GitHub Pages):** [https://pkfilipe.github.io/calculadora-media-simples/](https://pkfilipe.github.io/calculadora-media-simples/)

## Como usar
Abra o arquivo `index.html` em seu navegador, insira as 3 notas e clique em "Calcular Média".
